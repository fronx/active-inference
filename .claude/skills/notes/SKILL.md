# Notes Skill

Update `.claude/session-logs/notes.md` with current session state.

## Usage

```
/notes
```

## Instructions

1. Read the current `.claude/session-logs/notes.md`
2. Update it to reflect:
   - What was accomplished this session
   - Current state of work in progress
   - Significant commands run this session (pipeline invocations, long-running recordings, data processing — anything the user might want to recall next time). Always include the working directory and venv/conda env needed to run them.
   - Open questions or decisions pending
   - What to do next session
   - Key file paths relevant to current work
3. Preserve the established section structure (Current Focus, Recent Context, Open Threads, Commands, Next Steps, Key Locations)
4. Keep entries concise — this is a working document, not documentation
