This project has a slow pace — sessions happen every week or two, not daily.

**Why:** The user explicitly flagged that daily-cadence assumptions (e.g., 7 "No activity" log files for one quiet week) create noise.

**How to apply:** Session briefings show the last 3 *active* days (days with commits) rather than the last 3 calendar days. Done-stream pruning uses a 2-week threshold. Don't assume yesterday's context is fresh — always re-read notes and recent history.
